Placement Rule Standard ACL → as close to the destination as possible.
Extended ACL → as close to the source as possible.
SCENARIO
Beacon Hill Pediatrics must tighten access to the electronic health record server for a HIPAA review. "Staff hit the EHR over HTTPS and nothing else. No raw HTTP, no other ports to that box. The rest of the network is unaffected."
  • Staff 10.2.5.0/24 may reach EHR server 10.2.9.10 on TCP 443 only.
  • Any other staff traffic to that server is denied.
  • All other traffic is permitted.
Statement Palette — drag into the builder
access-list 110 deny ip 10.2.5.0 0.0.0.255 host 10.2.9.10
access-list 110 permit ip any any
access-list 110 permit tcp 10.2.5.0 0.0.0.255 host 10.2.9.10 eq 443
access-list 110 permit tcp 10.2.5.0 0.0.0.255 host 10.2.9.10 eq 80
access-list 110 permit udp 10.2.5.0 0.0.0.255 host 10.2.9.10 eq 443
access-list 110 deny ip any any
