Scenario
Meridian Pharma operates a clean-room research building with strict network segmentation. Four VLANs are in place: CORP, LAB (research), VOICE (IP phones), and GUEST. The switch team has completed all access-port work; the trunk to your new ISR is live. You need to configure four router subinterfaces with 802.1Q encapsulation so routing between all four VLANs comes up. "No host can reach another VLAN until you finish — get it done before 5 PM."

✓
1
Enable the parent interface Gi0/0
Before subinterfaces work, the physical parent has to be administratively up. Routers default to shutdown.
Enter interface config for the parent and take it out of shutdown.
Use interface Gi0/0 then no shutdown.
interface Gi0/0 no shutdown
✓
2
Subinterface for VLAN 100 (CORP) — 172.16.100.254/24
Create Gi0/0.100, tag it with encapsulation dot1q 100, and assign 172.16.100.254 255.255.255.0.
Enter interface Gi0/0.100. Subinterfaces don't exist until you enter them for the first time.
On a subinterface you need two things: encapsulation dot1q <vlan> and ip address.
interface Gi0/0.100 encapsulation dot1q 100 ip address 172.16.100.254 255.255.255.0
